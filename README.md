# Med-Safe-Net-Api

**Med-Safe-Net-Api** is a web-based system designed to enhance patient safety by monitoring their heart rate and fall activity, while enabling efficient caregiver-patient assignment. The system includes a Web API and an Angular dashboard, both deployed on Microsoft Azure.

---

## Features

- 📈 **Real-time Heart Rate Monitoring**  
  Continuously track patient heart rate and receive warnings for abnormal levels.

- 🚨 **Fall Detection Alerts**  
  Get notified immediately if a patient experiences a fall.

- 👩‍⚕️ **Patient-Caregiver Assignment**  
  Easily assign caregivers to patients for better management and oversight.

- 📊 **Interactive Dashboard**  
  A responsive Angular frontend to visualize patient data and alerts.
